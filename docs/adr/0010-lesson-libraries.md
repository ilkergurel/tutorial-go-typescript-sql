# ADR-0010: Lessons may use real libraries (local mode)

Date: 2026-11-13 · Status: accepted (owner approved zod, TanStack Query and the ts-test
dependencies on 2026-11-13)

## Context

The curriculum teaches pgx, errgroup, React, React Router, TanStack Query, zod, Vitest,
Testing Library, MSW and Playwright. Lesson code ran standard-library-only Go and plain
TypeScript: no network, no bundler, no packages. Lessons about those libraries could
only show code that never ran, which breaks the rule that every example runs.

## Decision

Lessons use the libraries the app itself installs, offline, with nothing persisting:

- **Go**: an example importing pgx, `golang.org/x/sync` or `golang.org/x/text` builds
  against a checked-in module template (`gorun/pgxlesson.go.mod/.sum`, generated by
  `go mod tidy`, kept equal to `server/go.mod` by a test) from the module cache. A pgx
  example also gets `DATABASE_URL` for an empty `run_` schema that is dropped afterwards.
- **Browser**: `scripts/build-lesson-libs.mjs` bundles react, react-dom, react-router-dom,
  @tanstack/react-query and zod into one ES module (one React instance); the runner
  passes it to the iframe as `data:` URLs in an import map, only when a lesson imports it.
- **ts-test**: a backend runtime runs Vitest (jsdom, Testing Library, MSW, typecheck) or
  Playwright with the installed Microsoft Edge (`channel: 'msedge'`, no browser
  download), in `.lesson-runs/` inside the project so packages resolve from its
  `node_modules`.

## Alternatives

- **Show library code without running it**: violates "every example runs".
- **npm install per run / a package registry proxy**: network and minutes per Run.
- **Serve libraries to the iframe from Vite**: the opaque-origin iframe would need CORS
  and a CSP exception for the app origin; data: URLs need neither.
- **Download Playwright's own Chromium**: ~500 MB; Edge is already on the machine.

## Consequences

- These lessons run in local mode only: the Docker runner image has neither the Go
  module cache, the app's node_modules, nor Edge. They answer 501 there.
- Library versions follow the app: upgrading React or zod can change lesson output;
  `npm run verify:lessons` after an upgrade shows which.
- The browser bundle is ~2.9 MB of development builds, parsed per run that uses it
  (well under a second); React's warnings reach the learner's stderr.
